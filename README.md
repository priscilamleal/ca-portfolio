# Personal Developer Portfolio

This project was created as part of a Code Academy challenge to practise web development fundamentals and showcase my technical skills and projects.

## 🛠️ Technologies Used

- **HTML5** — Semantic structure and content
- **CSS3** — Styling, layouts, Flexbox, and dark mode themes
- **JavaScript** — Interactive dark mode toggle
- **Git & GitHub** — Version control and source code management

## ✨ Features

- About Me section
- Technical Skills section
- Projects showcase
- Salesforce Certifications section
- Contact links to email, LinkedIn, and GitHub
- Interactive dark mode toggle
- Profile picture
